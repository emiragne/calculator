# REQUIREMENTS
The calculator app should:
1. Allow the user to input a number, then an operator, and then another number
2. Calculate the result of the following:
-  Addition
- Subtraction
- Multiplication
- Division by non-zero numbers
3. Output a clear error when an input is not acceptable (Division by zero, invalid operation, etc.)
4. Output the result of the operation

Examples inputs and outputs:
- 3 - 9 should output -6
- 8 / 3 should output 2.6666...
